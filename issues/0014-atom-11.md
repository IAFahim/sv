# Issue 0014 — Atom 11: Game/Frame composition layer (`Sv.Compose`)

Filed as GitHub issue #14 (open). Labels: `ai`, `area:compose`, `kind:feat`.
Contract touchpoint: new clauses 18–19 — bus 0029 (contract v1.0.4, pending ack).

## Problem

- Clause 7's frozen order is the most valuable thing sv owns, yet every host
  re-implements it as a ~40-line harness (`tests/Sv.NorthStar/NorthStarHarness.cs:
  189-234`) — and gets the host duties wrong at their peril (clause 13b effect-column
  zeroing, applied post-emit zeroing, writer discipline).
- The user-facing pain this answers: "where did `WalkTrackTimeline` come from" —
  generated tl pairs and kernel facades plug into user code with no declared home.
  The composition layer is that home, and the only one.

## Plan

- New package `Sv.Compose` — **the only sv package permitted to reference tl and
  ecs-kernels** (`Sv` core stays dependency-free, clause 8 unchanged).
- `Game.Create(schema, capacity)` builder → `.Event<T>()` → `.Timeline<TStep>()` →
  `.Kernel<TStep>()` → `.Build(world, input)`; capacity rounds per issue 0011.
- `Frame.Run(float dt)` encodes clause 7 verbatim as its method body:
  `Capture → Drain(+Reconcile per 0013) → RunIntrinsics/Recalculate →
  ZeroEffectColumns → Timeline.Apply/Advance → Kernel.Run → Conditions.Run →
  EmitFromApplied(+auto-zero) → Swap`. Each step is one line calling an existing
  public primitive — the frame owns order and host duties, never math.
- Timeline/Kernel hooks are generic structs (`struct WalkStep : ITimelineStep`)
  with static-generic dispatch — Burst-friendly, no boxing, no virtual calls; the
  tl 1.3/2.0 naming seam (`OnActive`/`ExecuteActive`, `ApplyLanes`/`ApplyChunk`)
  is absorbed here and nowhere else.
- All state allocated at `Build`; zero warm allocations on `Frame.Run`.
- Manual primitives remain public and contract-valid — the frame is sugar, not a cage.

## Acceptance gate

- New sample-style test: a full game loop driven solely by `Game` + `Frame.Run`
  (spawn, intrinsics, one timeline, one kernel, one event channel) with zero
  handwritten frame-order code; digest asserted against the equivalent manual
  NorthStar-style loop (bit-identical).
- Warm-path allocation receipt: 0 B over ≥ 2,000 frames.
- `sv.slnx` green default + `SV_CHECKED`; FMA grep clean; `Sv` core project still
  references nothing (test enforced).
