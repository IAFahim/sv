## Findings (bus-relevant)

- **tl version skew (incident class)**: the LOCAL tl HEAD `Tl.Bake` bakes an asset
  the PUBLISHED `Tl.Runtime 1.2.0` rejects ("TLB magic or version invalid"). tl's
  Directory.Build.props still says 1.2.0, so the format moved without a version bump
  (or the published pair lags). sv pins the published-pair receipt (tlb 1.2.0 tool +
  Tl.Runtime 1.2.0 runtime); the integrator should reconcile with the tl side.
- Bake tool requires a BARE namespace (no dots) for tracks/clips.
- The pair `Apply` throws "No consumer is registered" without the `Tl.Gen.CSharp`
  analyzer package in the consuming project — registration is generated, not manual.
- The checked-in `samples/Showcase/jump.tlb` in tl is a gitignored local artifact;
  a stale local copy fails to load (rebake per README). Not a tl repo defect.
